# Ascend Fitness

Mobile-first personal workout tracker / installable PWA.

## Included
- 4-day athletic strength + hypertrophy program
- Contrast strength/power blocks
- Fast kg / reps / RIR logging
- Automatic double progression
- Upper +2.5%, lower +5%, RIR 0 => -5%
- Persistent targets and workout history via localStorage
- Monthly calendar
- Progress overview
- JSON backup/import
- iOS safe-area-aware PWA UI

## Deploy
Import this repository into Vercel. Framework preset: Vite. No environment variables or backend configuration required.

## iPhone
After deployment, open the Vercel URL in Safari → Share → Add to Home Screen.
