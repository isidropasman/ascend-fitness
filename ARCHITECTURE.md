# Ascend architecture

- React + TypeScript + Vite
- Local-first state; no backend, account, analytics, ads, or LLM
- Deterministic progression engine in `src/engine.ts`
- Program definition isolated in `src/program.ts`
- Versioned local data model and JSON export/import
- Offline PWA service worker
- CI rejects TypeScript/build failures

## Product rule
Body metrics provide context only. They never silently change training loads. Load recommendations derive from completed sets, reps and RIR.
